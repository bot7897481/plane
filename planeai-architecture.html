🤖 AI-First Development

PlaneAI Agent

An autonomous AI coding agent that lives inside your project management workflow — reads tasks, writes code, runs tests, and closes issues automatically.

The Vision

An AI agent embedded in every coding project that reads the plan from Plane, understands the task, uses Claude to implement the code, runs the test suite, and autonomously marks tasks as complete — creating bug issues automatically when tests fail. Your projects manage themselves.

Autonomous Agent Workflow
STEP 01
📋
Read Plan
Agent polls Plane API for tasks assigned to "AI Agent" in the active cycle. Picks highest priority.
→
STEP 02
🧠
Understand
Marks issue "In Progress". Builds context: task description, acceptance criteria, relevant code.
→
STEP 03
💻
Implement
Claude writes the code using tools: reads files, writes changes, follows existing patterns.
→
STEP 04
🧪
Test
Runs the full test suite automatically. Checks coverage. Validates against acceptance criteria.
→
STEP 05
✅
Report Back
PASS → marks Done in Plane + adds implementation note. FAIL → creates Bug issue with full stack trace.

                                │  GET /api/v1/issues/?assignee=ai-agent&status=pending

┌─ PLANEAI AGENT SERVICE (FastAPI) ──────────────────────────────────────────┐
│                                                                             │
│  task_watcher.py  →  context_builder.py  →  agent_runner.py               │
│       │                    │                       │                        │

└───────────────────────────────┬────────────────────────────────────────────┘
                                │  anthropic.messages.create(tools=[...], model="claude-opus-4-6")
                                ▼
┌─ CLAUDE AGENT ─────────────────────────────────────────────────────────────┐
│                                                                             │
│  System: "You are a coding agent. Read the task, implement it, test it."  │
│                                                                             │
│  Tools available:                                                           │
│    read_file(path)         → reads any project file                        │
│    write_file(path, code)  → creates/edits code files                      │
